ЛР 6. Виртуальная машина «Квант-6». Стартовый набор
==================================================

Что внутри:
  kvant.py        — ваша машина (каркас с TODO). Работаете здесь.
  test_kvant.py   — автопроверка по главам. Не меняйте.
  DEMO.kv6        — демонстрационный картридж с известным результатом.
  BENCH.kv6       — бенчмарк для главы 7 (оптимизация).

Что добавить самим:
  <ваш номер>.kv6 — ваш личный картридж от преподавателя. Положите его в эту же папку.

Как начать в PyCharm:
  1. File > Open… и выберите эту папку.
  2. Откройте test_kvant.py, правый клик, Run 'test_kvant'.
     Внизу появится список глав: пока все «ещё не начаты».
  3. Откройте kvant.py и найдите первый TODO (глава 1).
  4. Запуск машины: вкладка Terminal внизу PyCharm, команды вида
        python kvant.py info DEMO.kv6
     (если «python» не находится — попробуйте «py kvant.py info DEMO.kv6»).

Задачник со всеми объяснениями — файл lab6_student.html (откройте в браузере).
Лабораторный журнал ведётся там же, на вкладке «Журнал». Для сдачи скачайте его
кнопкой «Скачать журнал для сдачи» и положите файл в эту папку.
